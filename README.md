# Content Management System Using Object-Oriented PHP

## Overview

This project demonstrates the development of a simple content management system built using object-oriented PHP principles and MySQL database integration.

## Technologies

* PHP
* MySQL
* HTML
* CSS
* JavaScript

## Features

* Content creation and management
* User management
* Dynamic page generation
* Database-driven architecture
* Object-oriented design

## Purpose

The project was developed to demonstrate object-oriented programming concepts and CMS architecture using native PHP.

## Skills Demonstrated

* PHP Development
* Object-Oriented Programming
* Database Integration
* Content Management Systems
* CRUD Operations
